## 🐛 Quick Fixes

### Port Already in Use?
```powershell
netstat -ano | findstr :3002
taskkill /PID <PID> /F
npm run web
```

### White Screen?
1. Clear cache (Ctrl + Shift + Delete)
2. Hard refresh (Ctrl + F5)
3. Check console (F12)

### Module Errors?
```powershell
npm install --legacy-peer-deps
npm run web
```
